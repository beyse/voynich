# E5 deviations

## Before the E5 Voynich statistic was computed

1. **Uncertainty by quire jackknife instead of page bootstrap.** Resampling pages with replacement duplicates pages. Duplicates add cross-copy pairs to the expected count but not to the observed count, which biases the index downward for types concentrated on a page. In the first control run most bootstrap intervals did not contain their own point estimate (for example LAT: G = +0.74, interval −0.56 to 0.03). The same defect led to rejecting the page bootstrap in the earlier project. The intervals are now G ± 1.96 SE from a leave-one-quire-out jackknife (Voynich quire labels, carried by all controls). The point estimates are unchanged.
