# Deviations from the preregistration

Each entry states when it was made relative to the Voynich results (Stage B).

## Made before any Stage B (Voynich) result was computed

1. **Gibberish formatting (data handling not foreseen in Section 4).** The transcriptions contain lines of underscores that separate the handwritten pages, leading `-` or `*` used as bullet marks, and trailing `-` marking a word hyphenated across a line break. Handling: underscore lines split a document into pages; bullet marks are removed; hyphenated fragments are kept as written, one token on each line, because that is what the writer put on each physical line. The document remains the unit for T2b, T3 and T6 as preregistered. T1 and T2 are additionally reported without the hyphenated breaks as a sensitivity analysis. A blank line ends a paragraph; the last line of a document is paragraph-final.
2. **T6a null computed exactly.** The mean of the within-page permutation null is computed analytically: for a page with n tokens, the expected repeat rate at any distance is the share of ordered token pairs that are equal (or at edit distance 1). This is the exact expectation of the 50-permutation null in Section 6 and removes its Monte Carlo error.
3. **T5 choice of K.** Nested leave-one-page-out cross-validation for the number of blocks is too slow. K is chosen inside each training fold by 5-fold cross-validation over pages, and the outer loop remains leave-one-page-out. Hands with fewer than 10 pages of at least 100 certain tokens are skipped (this excludes hand 5).
4. **T1 Monte Carlo precision.** With 20 re-pairings the Monte Carlo noise of the excess MI is as large as the between-group variation, and the jackknife multiplies it by about the square root of the number of groups (observed jackknife SE near 1 for the controls). The estimand is unchanged, but the null now uses 500 re-pairings, and the equal-size within-line samples are consecutive blocks of the within-line pairs in text order (averaged over all blocks) instead of 20 random subsamples. A closed-form bias correction (Miller–Madow) was checked and rejected because it overestimates the null by up to 70% for sparse tables.
5. **T1 null restricted to the page.** The preregistered null re-pairs pairs across the whole corpus. In a heterogeneous corpus this counts the association induced by page- or writer-specific glyph distributions as coupling. For the gibberish corpus, whose 38 writers invented different "languages", the break excess falls from 0.026 to 0.007 bits when re-pairing is restricted to the writer, while for a single Latin text it hardly changes (0.020 vs 0.019). The null therefore re-pairs only within the same page (gibberish: document) for both the break pairs and the within-line pairs. The same page-level heterogeneity is present in the Voynich text (drift by hand, section and page), so the corrected null applies to every corpus alike.
6. **T1 estimand made page-conditional.** With re-pairing restricted to the page, the pooled excess is still not additive over pages: for the gibberish corpus the within-line excess is 0.017 bits over all pairs but 0.057 bits averaged over break-sized blocks, because pooled MI mixes pages with different joint distributions. T1 therefore uses the page-conditional coupling: per page, excess MI over re-pairing within that page, averaged over pages. Equal numbers of pairs are kept per page, since each page's within-line pairs are cut into consecutive blocks of that page's number of break pairs. The null uses 200 re-pairings per page and block.

   **Disclosure.** While diagnosing entries 5 and 6, the T1 excess terms were also computed once on the Voynich text (break 0.004 bits, within-line 0.144–0.171 bits depending on the estimator). T1 is the prior test of Section 3, item 1, whose Voynich outcome (ratio about 0.03) was already known and declared. No other Voynich statistic has been computed.

   **Validation of entry 6.** Wrapped Latin (38 pages) was compared with the same text after a different random letter substitution on each page, which mimics writers with different invented alphabets without changing the true coupling. The pooled estimators break down under the substitution (pooled, all pairs: R changes from 0.61 to a meaningless 162 with negative excess; pooled, equal n: 0.80 to 2.02). The page-conditional estimator returns identical values for both versions (R = 1.29, jackknife SE 0.92), because MI within a page is invariant to relabelling. It is the only one of the three that is valid under writer heterogeneity. It is noisy when the coupling is weak and pages are short, which is reported with the result.
7. **LATV dropped.** The Vulgate reference file in `data/ref` is empty (a failed download in the earlier project), so the LATV control produced no data. The natural-language controls are LAT, ITA, GER and ENG.
